# LinkMind 🧠🔗

LinkMind is an intelligent URL shortener and resource categorization engine built with Go, PostgreSQL, Docker, and the Google Gemini API.

## Project Vision

More than just a URL shortener, LinkMind acts as a background indexer:
1. Generate a short link instantly.
2. The AI visits the URL asynchronously.
3. Metadata (summary, title, tags) is extracted and stored.

## Tech Stack
- **Backend:** Go (Chi router, Clean Architecture)
- **Database:** PostgreSQL
- **AI Integration:** Google Gemini API
- **Infrastructure:** Docker, Docker Compose
- **Deployment:** Railway / GitHub Actions
